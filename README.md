# ZETA Android App

독립 GeckoView 기반 제타 웹 클라이언트 (비공식). 기존 zeta-userscripts 저장소와 별개로 관리합니다.

## 0.2.1 Preview
- 로그인 확인된 GeckoView 160 엔진 및 SDK 37.0 빌드 구성 유지
- 새 설치 시 시스템 상하단 표시, 카카오톡 테마 기본 적용
- 기존 상단 플로팅 설정 버튼 제거; 프로필 헤더에 앱 설정 링크 추가 (실기기 UI 확인 필요)
- 종료 확인 창에도 앱 설정 접근 경로 유지
- 독립 테마 파일 `scripts/zeta-app-light.user.js`: 앱의 기존 카카오톡 테마 파생본이며 오류 제보 UI 제외. 다른 브라우저에서는 기존 기본 테마와 동시에 실행하지 마세요.
- 기존 배포 스크립트와 저장소 수정 없음. APK 빌드는 이 저장소의 테마 파일만 사용.
- 앱 내 커스텀 테마 편집기와 전체 페이지 라이트 모드 확장은 후속 구현 대상.

## APK
Actions → 최신 성공 빌드 → Artifacts → ZIP 압축 해제 → app-debug.apk.
테스트용 debug 서명입니다. 기존 설치본과 서명이 다르면 덮어쓰기 실패할 수 있습니다. 기존 로그인 데이터를 보존하려면 삭제하기 전에 확인하세요. 공개 릴리스 전 안정적인 서명키 및 라이선스 고지 마련 필요.

## 0.2.2 자동 업데이트
- 앱 시작 시 GitHub 정식 Release를 자동 조회합니다. 더 높은 versionCode의 APK가 있을 때만 알림을 표시하고, 사용자가 업데이트를 선택하면 외부 브라우저에서 APK를 다운로드합니다. 자동 설치는 하지 않습니다.
- 앱 설정에서 수동 확인 또는 자동 확인 끄기가 가능합니다.
- 정식 릴리스는 저장소 Actions Secret `ZETA_RELEASE_SIGNING` (JSON: keystore, password)을 설정한 뒤 생성합니다. 최초 1회 동일한 키를 설정하고 계속 보관하세요. 키가 없으면 테스트 APK만 빌드합니다.
- 릴리스 버전 코드는 1000 + workflow run number로 증가합니다. main 변경 시 테마 코드도 함께 빌드되어 정식 APK로 배포됩니다. 런타임 원격 JS 갱신은 구현하지 않았습니다.
- 과거 debug 서명 APK에서는 정식 서명 APK로 덮어쓰지 못할 수 있습니다. 서명 전환 때만 재설치가 필요하며 로컬 로그인 상태는 다시 설정해야 할 수 있습니다.

## 라이트 모드 2.0.0 (홈 화면 1차)
- 기존 카카오톡 파생 테마 전체를 삭제하고 첨부된 홈 HTML 구조에 맞춰 재작성했습니다.
- 배경, 상하단 메뉴, 피드, 카드, 그라데이션과 텍스트만 수정하며 기존 레이아웃 및 보라색 포인트를 유지합니다.
- CSS 1회 삽입, MutationObserver/타이머/DOM 반복 순회 없음. 홈 외 화면과 채팅 iframe은 추후 별도 구현합니다.
- 기존 공개 유저스크립트 저장소는 수정하지 않습니다.

## 0.2.3 독립 테마 자동 업데이트
- 앱 시작 및 백그라운드에서 복귀 시 지정된 공개 테마 스크립트의 CSS 리터럴만 HTTPS로 내려받아 적용합니다. 원격 JavaScript는 실행하지 않습니다.
- 정상 CSS를 기기에 보관하며 네트워크/형식 오류 시 마지막 정상 캐시 또는 APK 내 기본 CSS를 사용합니다.
- 앱 설정 → 테마 업데이트 확인에서 수동 조회 및 버전을 확인할 수 있습니다. 색상 변경은 열린 페이지에 기존 style 요소를 교체하는 방식이며 대화창 새로고침은 하지 않습니다.
- scripts/ 또는 README.md만 수정하면 APK 빌드를 시작하지 않습니다. 앱 코드 수정 시만 새 APK를 배포합니다.
- 현재 최상위 제타 페이지 전용이며 iframe 테마는 후속 HTML 검토 후 지원합니다.
