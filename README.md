# ZETA Android App

독립 GeckoView 기반 제타 웹 클라이언트 (비공식). 기존 zeta-userscripts 저장소와 별개로 관리합니다.

## 0.2.1 Preview
- 로그인 확인된 GeckoView 160 엔진 및 SDK 37.0 빌드 구성 유지
- 새 설치 시 시스템 상하단 표시, 카카오톡 테마 기본 적용
- 기존 상단 플로팅 설정 버튼 제거; 프로필 헤더에 앱 설정 링크 추가 (실기기 UI 확인 필요)
- 종료 확인 창에도 앱 설정 접근 경로 유지
- 독립 테마 파일 `scripts/zeta-app-light.user.js`: 앱의 기존 카카오톡 테마 파생본이며 오류 제보 UI 제외. 다른 브라우저에서는 기존 기본 테마와 동시에 실행하지 마세요.
- 기존 배포 스크립트와 저장소 수정 없음. APK 빌드는 이 저장소의 테마 파일만 사용.
- 앱 내 커스텀 테마 편집기와 전체 페이지 라이트 모드 확장은 후속 구현 대상.

## APK
Actions → 최신 성공 빌드 → Artifacts → ZIP 압축 해제 → app-debug.apk.
테스트용 debug 서명입니다. 기존 설치본과 서명이 다르면 덮어쓰기 실패할 수 있습니다. 기존 로그인 데이터를 보존하려면 삭제하기 전에 확인하세요. 공개 릴리스 전 안정적인 서명키 및 라이선스 고지 마련 필요.
